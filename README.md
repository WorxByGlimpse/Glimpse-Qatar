# Glimpse Qatar

Qatar version of the Glimpse website. Static HTML/CSS/JS, deployed on Vercel (`cleanUrls`).
Started as a snapshot of `elmarwanos/Glimpse-web` (UAE site). The two repos share no git
history and no remote, so nothing done here can touch the UAE site.

## Local preview

    npx serve .

## SEO rules (read before adding or copying a page)

Canonical, hreflang, Open Graph, `sitemap.xml` and `robots.txt` are generated by
`scripts/seo.py` from the file path. Never hand-edit the block between
`<!-- SEO:START -->` and `<!-- SEO:END -->`.

    python3 scripts/seo.py            # after adding/renaming a page or changing a <title>/description
    python3 scripts/seo.py --check    # verify only
    python3 scripts/seo.py --set-domain https://www.realdomain.qa

- Every page has a self-referencing canonical on the Qatar domain. It never points at the UAE site.
- Every page that also exists on the UAE site carries `en-QA`, `en-AE` and `x-default` hreflang.
- A page that exists only on the Qatar site goes into `QATAR_ONLY` in `scripts/seo.py` (no hreflang).
- `*.vercel.app` hosts are served with `X-Robots-Tag: noindex` (see `vercel.json`).

Open items before launch are in `QATAR-LAUNCH-CHECKLIST.md`.
